# Fonts

The site serves its fonts from here, so a page makes no request to a font
service. They are the variable woff2 files that Google Fonts serves, in the
`latin` and `latin-ext` subsets (the latter has the Czech and Slovak letters).
The `@font-face` rules are in `assets/css/fonts.css`.
